# NOVA AUTO

Sitio bilingüe de accesorios prácticos para coches, publicado en GitHub Pages: https://javiersteven13.github.io/nova-auto/

La tienda está en **vista previa**. Ningún artículo se ofrece todavía para compra y el sitio no cobra pagos. Los artículos mostrados son ideas de selección; no representan inventario confirmado.

## Qué falta para abrir las primeras ventas en Estados Unidos

- Elegir el modelo exacto de cada producto inicial y verificar muestra, contenido, compatibilidad, disponibilidad y reputación del proveedor.
- Confirmar por escrito el costo total puesto en Estados Unidos, el plazo real por destino, seguimiento y proceso de incidencias y devoluciones.
- Definir precio de venta a partir de costo, envío, impuestos aplicables, comisiones de cobro, devoluciones y margen objetivo. Publicar el precio final antes del pago.
- El correo de contacto `novaautoproducts@gmail.com` ya está publicado. Confirmar que recibe mensajes y responder desde esa cuenta; anunciar horarios o tiempos de respuesta solo cuando se puedan cumplir.
- Configurar una cuenta PayPal Business para la tienda y un enlace de pago por producto. La cuenta PayPal personal del propietario permanece separada si así lo prefiere.
- Publicar políticas reales de envío, devoluciones y privacidad, además de la identidad comercial requerida para el mercado donde opere el vendedor.
- Revisar el proceso completo de pedido, confirmación, atención y reembolso con información verdadera antes de habilitar botones de compra.

`index.html` es la versión en español y `en/index.html` la versión en inglés. Ambas deben actualizarse juntas. No publicar precios, reseñas, descuentos ni promesas de entrega sin verificación.
